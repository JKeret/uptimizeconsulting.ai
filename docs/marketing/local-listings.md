second. Both feed the same purpose: local citations that back up the
`/answers/` AEO pages and give happy clients somewhere to leave a review.

## Google Business Profile

- [ ] Go to business.google.com and start a new profile
- [ ] Business name: `Uptimize Consulting`
- [ ] Primary category: choose the category closest to "Business management
      consultant"
- [ ] Add a secondary category closest to "Computer consultant"
- [ ] Business type: service-area business, not a storefront — when asked
      whether customers visit the address, say no and do not show a public
      address
- [ ] Service area: Naperville, IL plus the wider Chicago metro (add
      Naperville first, then add surrounding Chicago-area cities/counties up
      to whatever radius Google's picker allows)
- [ ] Paste the services list above into the services/specialties section
- [ ] Paste the ready-to-paste description above into the business
      description field
- [ ] Add phone number (Jonathan's number — this profile is Jonathan-only,
      no shared/team line)
- [ ] Add website: `https://uptimizeconsulting.ai`
- [ ] Add the Starter page as the "appointment/booking" or secondary link if
      GBP offers that field: `https://uptimizeconsulting.ai/starter/`
- [ ] Complete verification — GBP will offer postcard, phone, or email
      depending on the category/account; pick whichever it offers and follow
      the prompts (postcard can take 1-2 weeks to arrive, so start this step
      early even if the rest of the profile isn't finished)
- [ ] Once verified, note the listing as a citation target (see below)

## Yelp

- [ ] Go to biz.yelp.com and claim (or create, if no listing exists yet) the
      business page for "Uptimize Consulting"
- [ ] Set the same category as GBP — closest match to "Business management
      consultant" / "Computer consultant" in Yelp's category list
- [ ] Paste the same ready-to-paste description from above
- [ ] Add the same service area (Naperville + Chicago metro), no public
      storefront address
- [ ] Add website: `https://uptimizeconsulting.ai/starter/`
- [ ] Add phone number (same as GBP)
- [ ] Complete Yelp's verification step (typically a phone call or text code)
- [ ] Skip all paid upsells — Yelp will push "Yelp Ads" / boosted placement
      during and after signup; decline all of it, this is a free listing only
- [ ] Once claimed, note the listing as a citation target (see below)

  the platform's current flow but land on the same end state (category,
  service area, description, phone, no storefront address, verification
  complete).
- This is a one-person listing. Do not add Jonathan's home address as a
  storefront, and do not invite other managers/owners onto either profile
  unless that changes deliberately later.
